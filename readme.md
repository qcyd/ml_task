# 原型网络小样本学习系统 (Prototypical Network for Few-Shot Learning)

基于 PyTorch 实现的原型网络小样本学习系统，支持训练可视化和交互式测试。

## 项目结构

## 功能特性

- **模型训练**：支持5-Way 1-Shot小样本学习任务
- **实时可视化**：训练损失和准确率曲线实时展示
- **跨域适配**：支持颜色扰动的跨域学习版本
- **交互式测试**：上传支持集和查询图片进行推理
- **距离度量**：展示各类别与查询图片的距离和置信度

## 环境要求

- Python 3.8+
- PyTorch 1.10+
- CUDA 11.0+（推荐使用GPU加速）
